# Development tools

- Use Context7 to check library documentation and examples against the versions used by this project.
- Use the frontend-ui-engineering skill when building or changing user-facing interfaces.
- Use Playwright CLI to verify browser interactions and inspect rendered pages after meaningful UI changes. On Windows use playwright-cli.cmd if PowerShell blocks the .ps1 shim.
- Supabase MCP is configured globally and disabled until a Supabase project is available. Scope it to the selected project before using it for database work.
